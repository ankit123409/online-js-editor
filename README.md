# Programiz-style JavaScript editor

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Features

- Monaco JavaScript editor with syntax highlighting
- Run JavaScript and capture console.log/info/warn/error
- Clear output
- Copy code
- Reset editor
- Resizable editor/output split on desktop

## Security note

This is a learning/demo compiler. The code runs in a sandboxed iframe, but this is not a hardened execution service. Do not expose it as a public multi-tenant code execution platform without additional isolation, resource limits, CSP, and server-side security review.
